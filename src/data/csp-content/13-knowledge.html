13.1 什么是 Master 定理？

Master 定理（主定理）是算法分析中用来快速求解分治算法递归式时间复杂度的一个公式化工具，是 CSP-S 初赛的高频考点。它适用于形如

\[ T(n) = a \cdot T\left(\frac{n}{b}\right) + O(n^c) \]

的递归式，其中：

  • \(a \ge 1\)：子问题的个数（每次递归产生几个子问题）；
  • \(b > 1\)：每个子问题的规模缩小倍数（规模变为原来的 \(1/b\)）；
  • \(O(n^c)\)：分解和合并操作所需的时间（\(c\) 为常数）。

适用条件：所有子问题的规模必须相同（即都是 \(n/b\)），且 \(a\)、\(b\)、\(c\) 均为常数。

13.2 三种情况（核心公式）

令 \(d = \log_b a\)（即以 \(b\) 为底 \(a\) 的对数），比较 \(d\) 与 \(c\) 的大小：

情况条件时间复杂度直观理解
情况一\(d < c\)\(O(n^c)\)合并操作占主导，叶子节点工作量可忽略
情况二\(d = c\)\(O(n^c \log n)\)每层工作量相同，共 \(\log n\) 层
情况三\(d > c\)\(O(n^d) = O(n^{\log_b a})\)子问题数量占主导，合并操作可忽略

记忆口诀：比大小，谁大听谁的；相等加 log。

13.3 详细推导与直观理解

递归树视角

将递归过程展开成一棵树：

  • 第 \(0\) 层：\(1\) 个节点，工作量 \(n^c\)；
  • 第 \(1\) 层：\(a\) 个节点，每节点工作量 \((n/b)^c\)，总工作量 \(a \cdot (n/b)^c\)；
  • 第 \(2\) 层：\(a^2\) 个节点，每节点工作量 \((n/b^2)^c\)，总工作量 \(a^2 \cdot (n/b^2)^c\)；
  • ……
  • 第 \(k\) 层：\(a^k\) 个节点，总工作量 \(a^k \cdot (n/b^k)^c = n^c \cdot (a/b^c)^k\)。

关键比值：\(r = \dfrac{a}{b^c}\)

  • 若 \(r < 1\)（即 \(a < b^c\)，等价于 \(\log_b a < c\)）：每层工作量递减，总工作量由第 0 层决定 → \(O(n^c)\)；
  • 若 \(r = 1\)（即 \(a = b^c\)，等价于 \(\log_b a = c\)）：每层工作量相同，共 \(\log_b n\) 层 → \(O(n^c \log n)\)；
  • 若 \(r > 1\)（即 \(a > b^c\)，等价于 \(\log_b a > c\)）：每层工作量递增，总工作量由叶子层决定 → \(O(n^{\log_b a})\)。

13.4 详细例题

例 1：归并排序

\[ T(n) = 2T(n/2) + O(n) \]

  • \(a = 2,\ b = 2,\ c = 1\)，\(d = \log_2 2 = 1\)；
  • 因为 \(d = c = 1\)，属于情况二；
  • 时间复杂度：\(O(n^1 \log n) = O(n \log n)\)。

例 2：二分查找

\[ T(n) = T(n/2) + O(1) \]

  • \(a = 1,\ b = 2,\ c = 0\)，\(d = \log_2 1 = 0\)；
  • 因为 \(d = c = 0\)，属于情况二；
  • 时间复杂度：\(O(n^0 \log n) = O(\log n)\)。

例 3：二叉树遍历

\[ T(n) = 2T(n/2) + O(1) \]

  • \(a = 2,\ b = 2,\ c = 0\)，\(d = \log_2 2 = 1\)；
  • 因为 \(d = 1 > c = 0\)，属于情况三；
  • 时间复杂度：\(O(n^1) = O(n)\)。

例 4：Strassen 矩阵乘法

\[ T(n) = 7T(n/2) + O(n^2) \]

  • \(a = 7,\ b = 2,\ c = 2\)，\(d = \log_2 7 \approx 2.807\)；
  • 因为 \(d > c\)，属于情况三；
  • 时间复杂度：\(O(n^{\log_2 7}) \approx O(n^{2.807})\)。

例 5：递归式 \(T(n) = 3T(n/4) + n \log n\)

  • \(a = 3,\ b = 4\)，但 \(f(n) = n \log n\)，不是纯 \(n^c\) 形式；
  • 严格来说，Master 定理的标准形式要求 \(f(n) = O(n^c)\)，这里 \(f(n)\) 带 log 因子，需要判断是否属于情况二的扩展；
  • 实际上 \(\log_4 3 \approx 0.793 < 1\)，属于情况一，但 \(f(n) = n \log n\) 比 \(n^c\) 稍大；
  • 更严谨地，此式属于情况一的扩展，结果为 \(O(n \log n)\)。

注意：Master 定理的三种标准形式要求 \(f(n)\) 是纯多项式 \(n^c\)。如果 \(f(n)\) 带有 \(\log\) 因子，需要更细致的分析。

例 6：补充情况

\[ T(n) = 2T(n/2) + O(n \log n) \]

  • 这里 \(f(n) = n \log n\)，不属于标准 Master 定理的三种情况（因为 \(f(n)\) 不是纯 \(n^c\)）；
  • 但根据扩展结论，时间复杂度为：\[ O(n \cdot (\log n)^2) \]

推导思路：递归树中，每层工作量为 \(n \log(n/2^k)\)，共 \(\log n\) 层，求和近似为 \(O(n \log^2 n)\)。

13.5 常见陷阱与注意事项

陷阱说明
子问题规模必须相同如 \(T(n) = T(n-1) + T(n-2) + 1\) 不能用 Master 定理
\(f(n)\) 必须是纯多项式如 \(f(n) = n \log n\) 需要扩展分析
\(a\)、\(b\) 必须是常数不能依赖于 \(n\)
底数 \(b\) 必须 > 1否则递归不收敛
正则条件（情况三）需要验证 \(a f(n/b) \le c f(n)\)，大部分题目自动满足
不要混淆 \(\log_b a\) 与 \(\log_a b\)注意底数和真数的位置

13.6 扩展：带有 log 因子的情况

若 \(T(n) = aT(n/b) + O(n^c \log^k n)\)，则：

  • 若 \(\log_b a < c\)：\(O(n^c \log^k n)\)；
  • 若 \(\log_b a = c\)：\(O(n^c \log^{k+1} n)\)；
  • 若 \(\log_b a > c\)：\(O(n^{\log_b a})\)。

例：\(T(n) = 2T(n/2) + O(n \log n)\)，\(a=2,\ b=2,\ c=1,\ k=1\)，\(\log_b a = 1 = c\)，所以 \(O(n \log^2 n)\)。

13.7 练习题

练习 1

\[ T(n) = 4T(n/2) + O(n) \] 求时间复杂度。

答案：\(a=4,\ b=2,\ c=1\)，\(d = \log_2 4 = 2 > 1\)，情况三，\(O(n^2)\)。

练习 2

\[ T(n) = 2T(n/4) + O(\sqrt{n}) \] 求时间复杂度。

答案：\(a=2,\ b=4,\ c=0.5\)，\(d = \log_4 2 = 0.5 = c\)，情况二，\(O(\sqrt{n} \log n)\)。

练习 3

\[ T(n) = 8T(n/2) + O(n^2) \] 求时间复杂度。

答案：\(a=8,\ b=2,\ c=2\)，\(d = \log_2 8 = 3 > 2\)，情况三，\(O(n^3)\)。

练习 4

\[ T(n) = T(n/2) + O(n) \] 求时间复杂度。

答案：\(a=1,\ b=2,\ c=1\)，\(d = \log_2 1 = 0 < 1\)，情况一，\(O(n)\)。

练习 5

\[ T(n) = 2T(n/2) + O(n^2) \] 求时间复杂度。

答案：\(a=2,\ b=2,\ c=2\)，\(d = \log_2 2 = 1 < 2\)，情况一，\(O(n^2)\)。

练习 6

\[ T(n) = 3T(n/3) + O(n) \] 求时间复杂度。

答案：\(a=3,\ b=3,\ c=1\)，\(d = \log_3 3 = 1 = c\)，情况二，\(O(n \log n)\)。

练习 7

\[ T(n) = 2T(n/2) + O(n \log^2 n) \] 求时间复杂度。

答案：属于扩展情况，\(a=2,\ b=2,\ c=1,\ k=2\)，\(d = c = 1\)，所以 \(O(n \log^3 n)\)。

13.8 总结速查表

递归式形式条件时间复杂度
\(T(n) = aT(n/b) + O(n^c)\)\(\log_b a < c\)\(O(n^c)\)
\(T(n) = aT(n/b) + O(n^c)\)\(\log_b a = c\)\(O(n^c \log n)\)
\(T(n) = aT(n/b) + O(n^c)\)\(\log_b a > c\)\(O(n^{\log_b a})\)
\(T(n) = aT(n/b) + O(n^c \log^k n)\)\(\log_b a = c\)\(O(n^c \log^{k+1} n)\)

核心步骤：

  1. 识别 \(a\)、\(b\)、\(c\)；
  2. 计算 \(d = \log_b a\)；
  3. 比较 \(d\) 与 \(c\)；
  4. 套用公式。

13.9 历年真题

【2025-S-11】递归关系式 $T(n) = 2T(n/2) + O(n^2)$ 描述了某个分治算法的时间复杂度。请问该算法的时间复杂度是多少？

A. O(n)

B. O(n log n)

C. O(n²)

D. O(n² log n)

答案：C

解析：递归式为 \(T(n) = 2T\left(\frac{n}{2}\right) + O(n^2)\)。根据 Master 定理：\(a = 2\)，\(b = 2\)，\(c = 2\)，\(\log_b a = \log_2 2 = 1\)。比较 \(\log_b a\) 与 \(c\)：

\[ \log_b a = 1 < 2 = c \]

属于 Master 定理的情况一（合并代价占主导），因此 \(T(n) = O(n^c) = O(n^2)\)，所以选 C。
