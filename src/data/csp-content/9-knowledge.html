9.1 Linux 终端常用文件与目录操作命令

Linux 终端通过命令行完成文件/目录的增删改查、权限管理等操作，是 CSP-S 初赛选择题第 1~2 题的高频考点。

高频命令详解

命令功能说明语法格式实操实例
pwd打印当前工作目录的绝对路径（Print Working Directory）pwd输入 pwd，输出 /home/noi/code，表示当前在 code 目录下
cd切换工作目录（Change Directory）cd 目标路径cd .. 返回上一级目录；cd /home 切换到根目录下的 home 文件夹；cd ~ 切换到当前用户的家目录
ls列出当前目录下的文件和子目录（List）ls [选项] [路径]ls 普通列出文件；ls -l 详细列出文件权限、大小、修改时间；ls -a 显示所有文件（包括隐藏文件）
mkdir创建新目录（Make Directory）mkdir 目录名mkdir problem 在当前目录创建 problem 文件夹
rm删除文件或目录（Remove）rm [选项] 目标rm test.cpp 删除文件 test.cpp；rm -r dir 递归删除 dir 目录及其所有内容
cp复制文件/目录（Copy）cp 源文件 目标路径cp a.cpp b.cpp 将 a.cpp 复制为 b.cpp
mv移动文件/目录，也可用于重命名（Move）mv 源文件 目标路径mv old.cpp new.cpp 将文件重命名为 new.cpp；mv a.cpp ../ 将 a.cpp 移动到上一级目录
cat查看文件全部内容（Concatenate）cat 文件名cat main.cpp 直接在终端打印 main.cpp 的全部代码
chmod修改文件权限chmod 权限 文件名chmod 755 a.out 给可执行文件设置读写执行权限
touch创建空文件touch 文件名touch data.in 创建一个空的输入文件

初赛高频考点：pwd、cd、ls、rm -r 是出现频率最高的四个命令。

9.2 Linux 常见文本编辑工具

核心工具：Vim / Vi —— 是 Linux 系统最通用的终端文本编辑器，也是竞赛环境的标准编辑工具，分为三种工作模式。

1、三种模式与切换

  • 命令模式：默认进入模式，用于执行删除、复制、粘贴等操作；按 Esc 键可从其他模式回到命令模式。
  • 插入模式：用于输入、编辑文本；在命令模式按 i / a / o 进入，左下角显示 -- INSERT --。
  • 底行模式：用于保存、退出、查找等操作；在命令模式按 : 进入。

2、常用命令

模式命令功能
命令模式dd删除光标所在的一整行
命令模式yy复制光标所在的一整行
命令模式p粘贴已复制/删除的内容
命令模式u撤销上一步操作
底行模式:w保存文件（write）
底行模式:q退出编辑器（quit）
底行模式:wq保存并退出
底行模式:q!强制退出，不保存修改

3、补充工具：nano

轻量级简易编辑器，操作更简单，无需记忆模式切换，适合新手；但竞赛环境中 Vim 是默认通用工具。

9.3 g++ 编译命令与常用编译选项

将 C++ 源文件（.cpp）编译为可执行文件，是代码运行的核心步骤。

基础编译命令

g++ 源文件.cpp -o 可执行文件名

实例：g++ main.cpp -o main 将 main.cpp 编译生成名为 main 的可执行文件；不写 -o 时，默认输出文件名为 a.out。

高频编译选项详解

选项功能说明完整实例
-o 文件名指定输出的可执行文件名称g++ test.cpp -o test
-g生成调试信息，用于 GDB 调试；不加则无法断点调试g++ test.cpp -o test -g
-O2开启二级代码优化，提升程序运行速度；竞赛提交常用g++ test.cpp -o test -O2
-O0关闭所有优化，调试时推荐使用g++ test.cpp -o test -O0
-Wall开启所有编译警告，帮助发现代码隐患g++ test.cpp -o test -Wall
-std=c++11 / -std=c++14 / -std=c++17指定使用的 C++ 语言标准g++ test.cpp -o test -std=c++14
-D宏名编译时定义宏，常用于条件编译g++ test.cpp -DDEBUG
-lm链接数学库，老版本编译器使用 <cmath> 时需要g++ test.cpp -o test -lm

初赛高频考点：-o、-g、-O2、-std 是选择题核心考点。

9.4 time 命令查看程序运行用时

统计程序运行的 CPU 时间与真实耗时，用于评估算法效率、检测是否超时。

使用方法

time ./可执行文件

实例：time ./main 运行 main 程序，结束后输出三段时间。

输出三项含义

输出项全称含义
real真实时间从程序启动到结束的墙上总时间，包含等待时间
user用户态时间程序在用户态执行代码的 CPU 时间，不包含系统调用
sys内核态时间程序在内核态执行系统调用的 CPU 时间

竞赛中核心关注 user 时间，它代表算法实际消耗的 CPU 运算时间；1 秒时限对应 user 时间约 1s 左右。

9.5 GDB 调试工具使用

Linux 下的命令行调试工具，可以设置断点、单步执行、查看变量值，用于排查运行时错误、逻辑错误。

使用前提

编译时必须加上 -g 选项，生成带调试信息的可执行文件：

g++ test.cpp -o test -g

启动与退出

  • 启动调试：gdb ./可执行文件名，例如 gdb ./test
  • 退出 GDB：在 GDB 界面输入 quit（简写 q）

高频调试命令

命令（简写）功能说明
run（r）运行程序，直到遇到断点或程序结束
break 行号/函数名（b）设置断点，例如 b 10 在第 10 行设断点
next（n）单步执行，遇到函数直接跳过，不进入函数内部
step（s）单步执行，遇到函数会进入函数内部
print 变量名（p）打印变量当前的值，例如 p ans
continue（c）从断点处继续运行，直到下一个断点
list（l）列出当前位置附近的源代码
backtrace（bt）查看函数调用栈，排查段错误时常用

9.6 历年 CSP-S / NOIP 初赛真题汇总

1. 【2024 CSP-S 提高级初赛】

题目：在 Linux 系统中，如果你想显示当前工作目录的路径，应该使用哪个命令？（ ）

A. pwd　B. cd　C. ls　D. echo

答案：A

选项逐一分析：

  • A. pwd：全称是 Print Working Directory，核心功能就是打印并显示当前工作目录的绝对路径，完全符合题意。
  • B. cd：全称是 Change Directory，作用是切换工作目录（例如 cd .. 返回上一级目录），而非显示当前路径。
  • C. ls：全称是 List，作用是列出当前目录下的文件和子目录列表，不显示当前所在路径。
  • D. echo：功能是在终端输出指定的文本或变量内容，和目录路径查看无关。

速记总结：四个基础命令的核心区别——pwd 看「当前在哪」，cd 去「切换到哪」，ls 看「目录里有啥」，echo 输出「指定内容」。

2. 【2021 CSP-S 提高级第一轮】

题目：在 Linux 系统终端中，用于列出当前目录下所含的文件和子目录的命令为（ ）。

A. ls　B. cd　C. cp　D. all

答案：A

解析：ls 是 list 的缩写，用于列出目录内容；cd 切换目录；cp 复制文件。

3. 【2022 CSP-S 提高级第一轮】

题目：在 Linux 系统终端中，用于切换工作目录的命令为（ ）。

A. ls　B. cd　C. cp　D. all

答案：B

解析：ls 是 list 的缩写，用于列出目录内容；cd 切换目录；cp 复制文件；all 不存在这个命令。

4. 【2023 CSP-S 提高级第一轮】

题目 1：在 Linux 系统终端中，以下哪个命令用于创建一个新的目录？（ ）

A. newdir　B. mkdir　C. create　D. mkfolder

答案：B

选项逐一分析：

  • A. newdir：Linux 系统不存在这个标准命令，属于无意义的干扰选项。
  • B. mkdir：全称是 Make Directory，是 Linux 系统中专门用于创建新目录的标准命令，语法为 mkdir 目录名，完全符合题意。
  • C. create：不是 Linux 终端的标准操作命令，create 常见于编程语言、数据库语法中，不用于终端创建目录。
  • D. mkfolder：Linux 系统中没有该命令，"folder（文件夹）"是 Windows 系统的常用说法，Linux 中统一称为目录（directory），对应命令为 mkdir。

记忆补充：Linux 中创建文件用 touch，创建目录用 mkdir，二者是初赛最常考的一对"创建类"命令。

5. 【2023 CSP-S 提高级第一轮】

题目 2：以下哪个命令，能将一个名为 "main.cpp" 的 C++ 源文件，编译并生成一个名为 "main" 的可执行文件？（ ）

A. g++ -o main main.cpp　B. g++ -o main.cpp main　C. g++ main -o main.cpp　D. g++ main.cpp -o main.cpp

答案：A

核心规则：-o 是 output 的缩写，-o 后面必须紧跟输出的可执行文件名，源文件作为编译输入放在另一侧。语法两种等价写法：

g++ 源文件.cpp -o 输出文件名
g++ -o 输出文件名 源文件.cpp

选项逐一分析：

  • A. -o 后紧跟目标可执行文件名 main，输入源文件为 main.cpp，语法完全正确。
  • B. -o 后错误地写成了源文件名 main.cpp，会将输出文件命名为 main.cpp 并覆盖原始代码；同时将 main 当作输入文件，逻辑完全颠倒。
  • C. 将 main 作为输入文件、main.cpp 作为输出文件，完全颠倒了源文件和目标文件的角色。
  • D. 输出文件与源文件同名，会直接覆盖原始代码文件，且生成的可执行文件并不是题目要求的 main。

易错提醒：竞赛中最常见的坑就是混淆 -o 后接的内容——记住 -o 接输出，源文件是输入，永远不会出现 -o 源文件.cpp 的正确用法。
